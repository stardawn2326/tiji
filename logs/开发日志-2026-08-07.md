# 开发日志 2026-08-07

## E-004-001：Windows 中文路径兼容

- 发生了什么：Android Gradle Plugin 拒绝在中文路径下应用项目插件。
- 原因：AGP 默认检测 Windows 非 ASCII 路径并中止构建。
- 解决：在项目 `gradle.properties` 写入 `android.overridePathCheck=true`，并保留工程4既定目录。
- 结论：中文项目目录可构建，但新项目仍应优先使用 ASCII 路径；若必须遵循既定中文目录，需要显式记录该兼容开关。

## E-004-002：Gradle 代理与 SDK 版本

- 发生了什么：Gradle 首次解析依赖长时间无输出，SDK 命令行工具还出现 SDK XML 版本警告。
- 原因：Gradle 不会自动把当前 shell 的 `HTTPS_PROXY` 环境变量转换为 JVM 代理属性；新 SDK 命令行工具与 AGP 的 XML 版本提示属于工具代际差异。
- 解决：在项目 `gradle.properties` 写入本机代理属性；补装 AGP 需要的 Build Tools 34；保留 API 35 作为 compile SDK。
- 结论：工程构建说明必须包含代理配置位置和项目内缓存路径，避免依赖全局环境。

## E-004-003：Gradle 测试执行器中文路径

- 发生了什么：`testDebugUnitTest` 在原中文目录下无法加载 `GradleWorkerMain`，但 APK 编译与 lint 正常。
- 原因：Windows Gradle 测试 worker 的类路径处理对中文路径不稳定。
- 解决：临时将工程根映射到 ASCII 驱动器 `T:` 运行测试，测试通过后解除映射。
- 结论：该映射只改变访问路径，不复制或移动工程文件；后续可考虑将项目迁移至 ASCII 路径，但当前需遵守工程目录铁律。

## E-004-004：兼容视觉 AI 的安全调用边界

- 发生了什么：原设置页虽然能加密保存 API Key，但服务地址和模型不会持久化，也没有网络调用实现。
- 解决：增加 OpenAI 兼容 `chat/completions` 客户端、HTTPS 限制、连接测试、结构化 JSON 校验和可理解的鉴权/限流/服务端错误；首次上传前展示隐私说明，且只在用户主动点击时上传当前图片。
- 结论：离线 OCR 与视觉 AI 必须是并列路径；任何网络失败都不能覆盖或删除本地原图、OCR 和人工内容。

## E-004-005：移动端大图处理内存控制

- 发生了什么：直接对相机原图逐像素增强会同时持有源 Bitmap、输出 Bitmap 和像素数组，存在内存峰值风险。
- 解决：处理前按最长边约 2000 像素进行幂次采样，AI 上传前按约 1600 像素与 JPEG 82% 压缩；每次处理生成新文件，通过历史路径实现无损撤销。
- 结论：图片功能不仅要看算法效果，还必须限制解码尺寸、避免主线程执行并提供可恢复操作。

## E-004-006：DeepSeek 模型名兼容

- 发生了什么：真实设备测试中，用户将服务地址设置为 `https://api.deepseek.com`、模型填写为 `Deepseek`，服务端返回 HTTP 400，提示模型名无效。
- 原因：OpenAI 兼容接口仍要求传入服务商的精确模型 ID，显示名称不能直接作为 `model` 参数。
- 解决：增加 OpenAI、DeepSeek、自定义三类预设；DeepSeek 默认填入 `deepseek-v4-flash`，并对旧的 DeepSeek 地址/错误显示名配置自动纠正；补充模型预设回归测试。
- 结论：AI 配置不能只提供自由文本输入，必须同时提供可见的服务商模板和可解释的错误提示。

## E-004-007：低质量离线 OCR 收敛

- 发生了什么：实际体验中离线 OCR 对题目图片的识别效果不稳定，容易把错误文本带入错题内容。
- 决策：移除 OCR 入口、服务类和 ML Kit OCR 依赖；保留手工录入与图片保存，并将联网识题/解题放入独立 AI 解题流程。
- 结论：识别质量不足时，宁可让用户明确确认 AI 结果或手工录入，也不要用不可靠的自动文本污染错题库。

## E-004-008：录入分流与上传历史

- 决策：拍照录题只负责保存题图和人工元数据；AI 解题单独负责生成题目、答案和解析，结果全部保持可编辑。
- 实现：新增题目类型、上传时间字段和 Room 迁移；错题库可按上传时间查询、批量勾选并合并导出 PDF；复习计划增加每日数量、科目过滤和未完成顺延。
- 结论：上传时间作为分类与追溯依据，AI 与人工录入职责清晰，避免低质量 OCR 自动污染题库。
