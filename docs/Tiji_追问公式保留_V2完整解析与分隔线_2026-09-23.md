# 追问公式保留、V2 完整解析与分隔线

## 公式缺失修复

- 发现可复现的丢公式路径：结构化公式片段原先只读取 `latex`，模型把公式放在 `text`、`content`、`value` 时会被当作空片段跳过。
- 追问及 V2 解题解析现在优先读取标准字段，并兼容上述字符串字段；标准字段为空时继续查找，不凭空补写公式。
- 追问的流式恢复改用识别 JSON 字符串和转义的对象扫描器，保留字段顺序变化、字段别名及包含花括号的完整公式，不再依赖固定字段顺序的正则。
- 保存的原始回复不改写，已有回复仍在显示时解析。若服务端本来没有返回某个公式，本地无法恢复不存在的内容。
- 未取得截图对应的手机原始返回，不能断言上述问题是该截图的唯一原因。

## V2 解答完整性

- 原提示没有明确的“压缩解析”指令或字数上限，但对推导只要求“必要推导”。
- 已明确 V2 仅规定传输结构，不要求精简解答；要求说明方法、条件、关键代入和变形、分类讨论及必要检验，不用“显然”“计算可得”替代关键步骤。
- 输出完整教学解答，不输出模型内部思考内容；未改变思考模式配置。
