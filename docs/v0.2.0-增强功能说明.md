# 题迹 v0.2.0 增强功能说明

## 视觉 AI

- 协议：OpenAI 兼容的 `POST /chat/completions`。
- 配置：服务地址、视觉模型名称、API Key；禁止非本机明文 HTTP 地址。
- 预设：内置 OpenAI 与 DeepSeek；DeepSeek 当前默认使用 `https://api.deepseek.com` + `deepseek-v4-flash`，也可切换到 `deepseek-v4-pro` 或自定义兼容服务。
- 输出：题目标题、题干、答案、解析、科目、知识点、标签和 1–5 难度。
- 安全：API Key 使用 Android Keystore AES-GCM 加密；网络错误不会清除原图、OCR 或手工内容。
- 隐私：仅主动点击时上传当前题图，首次调用前明确确认，不记录 Authorization 或图片正文日志。

## 图片处理

图片在应用私有目录中处理，支持旋转 90°、对比度增强、灰度、黑白扫描、智能内容裁边和逐步撤销。处理时按最长边约 2000 像素采样，视觉 AI 上传前按最长边约 1600 像素和 JPEG 82% 压缩，以控制内存与流量。

## 主题与动效

配色包括粉白、蓝白、薄荷和柔紫；显示模式包括跟随系统、浅色和深色。选择通过 DataStore 持久化，主题、详情展开、处理状态与卡片尺寸变化均使用 Compose 动效。

## 已知边界

- 不内置开发者 API Key，服务费用与可用性由用户选择的第三方服务决定。
- 智能裁边基于内容边界，不等同于四角可调的完整透视变换。
- Debug APK 使用 Android 调试证书，仅适合侧载测试，不适合应用商店发布。
