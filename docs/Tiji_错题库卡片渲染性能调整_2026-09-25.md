# 错题库卡片渲染与导航位置调整（2026-09-25）

## 本次行为

- 冷缓存中的公式内容才通过现有 KaTeX/WebView 路径排版并生成截图；后续组合先查内存、再查磁盘，命中后直接显示缓存图片并跳过 WebView。文本内容和数据库数据不被改写。
- 首次渲染节流仅约束缓存未命中的公式卡片，缓存查找在节流之前完成，因此从二级页返回或切回错题库时不会为已有截图再次渲染。
- 图片只在网页渲染完成标记返回、连续三次版面尺寸一致、Compose 视图高度已完成布局后生成，降低公式未完成就被固定成图片的风险。
- 卡片渲染图片缓存有内存和磁盘上限；应用私有缓存可自行淘汰，不写入用户题库或备份文件。
- 一级页面列表状态由导航容器持有。错题库打开详情、录题再返回会恢复进入前的可见条目和像素偏移；底部切换一级页面时仍回到顶部。其他一级列表及知识点列表也复用各自的列表状态。
- 保存状态键包含 back stack entry ID，避免相同路由在快速动画转场中重叠组合时重复注册同一个保存键。
- 底部导航判断当前页时读取 NavController 最新 back stack entry，避免快速点按时用旧的 Compose 路由值发起重复导航。
- 2026-09-26：错题库题目正文与复习卡片统一用正文色；旧浅色截图因缓存键变化而重新生成一次。
