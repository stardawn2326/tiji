## 可复现本地回归

通过 `scripts/architecture-audit.init.gradle` 创建独立测试 applicationId `com.tiji.mistakes.audit`，保护模拟器中原应用的数据。

```powershell
./gradlew.bat -I scripts/architecture-audit.init.gradle :app:compileDebugUnitTestKotlin :app:exportAuditClasspath :app:connectedDebugAndroidTest --offline --no-parallel --max-workers=1 --console=plain
python scripts/run-audit-unit-tests.py
```

本地需使用项目既有 JDK17、Android SDK 与已下载 Gradle 依赖。JVM 回退执行器用于 Windows 中文路径下 Gradle 测试工作进程加载类失败；GitHub Linux CI 仍运行常规 `testDebugUnitTest`。
