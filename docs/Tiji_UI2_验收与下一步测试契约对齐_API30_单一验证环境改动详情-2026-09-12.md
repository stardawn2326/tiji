# Tiji UI 2.0 测试契约对齐与 API30 单一验证环境改动详情

日期：2026-09-12

分支：`codex/ui-2.0-paper-blue`

## 执行边界

本轮保留 UI 2.0 纸张蓝结构和业务逻辑，只对测试契约、测试入口及 Android 版本配置做可追溯调整。验证环境统一为已有的 `tiji-api30` AVD（Android API 30），不创建或使用第二套 Android 验证环境。按验收要求未进行视觉检查，也未合并到 `main`。

## 代码改动

### 稳定筛选定位

- `app/src/main/java/com/tiji/mistakes/ui/library/LibraryScreen.kt`
  - 为掌握度选项增加 `library_mastery_option_0..3` 稳定 `testTag`。
  - 为掌握度和难度两组弹窗选项增加容器 tag，支持测试在不同屏幕尺寸上滚动到目标选项。
- `app/src/androidTest/java/com/tiji/mistakes/LibraryFilterTest.kt`
  - 使用稳定 tag 定位筛选选项，移除重复文案索引选择器。
  - 打开弹窗前将筛选栏滚回可见区域，弹窗内等待并滚动到目标 tag。

### 知识点测试 Host

- 新增 `app/src/androidTest/java/com/tiji/mistakes/KnowledgeTestHost.kt`。
  - 从真实 Room 数据库、`MistakeRepository` 和 `WeaknessCalculator` 加载知识点、关联错题、复习历史及统计结果。
  - 直接渲染生产 `KnowledgeDetailScreen`。
  - 为专项复习测试提供仅存在于 androidTest 的 Host，使用真实 `MistakeViewModel`、真实 `ReviewSessionPlan` 和生产 `ReviewQuestionScreen`。
  - 不恢复已删除的 Library 知识点入口，不复制生产算法。

### 知识点详情与统计

- `KnowledgeDetailAnalyticsTest.kt` 直接渲染真实知识点详情，验证 30 天内统计值为 `2`。
- `KnowledgeExplorerTest.kt` 直接渲染数学知识点详情，验证数学关联错题存在、物理同名标签错题隔离、移除的“查看相关错题”入口不存在。

### 专项复习与重建

- `FocusedReviewUiTest.kt` 用真实知识点关联队列创建 `ReviewSessionSource.KNOWLEDGE_POINT` 复习计划，通过真实 `MistakeViewModel` 进入生产复习问答与总结页面，保留手势、评分、总结和返回详情断言。
- `FocusedReviewRecreationTest.kt` 在 Activity 重建后重新绑定真实 ViewModel 与测试 Host，保留答题状态、题目索引、总结恢复和重复评分幂等断言。

### Android 版本与验证链路

- `app/build.gradle.kts`：`targetSdk` 固定为 `34`，`compileSdk` 使用依赖要求的最低版本 `34`；运行验证仍固定在 API30。
- `tools/paddleocr-upstream-20260814/deploy/ppocr-android/ppocr-sdk/build.gradle.kts`：OCR 子模块 `compileSdk` 同步为 `34`。
- `.github/workflows/android.yml`：只保留 API30 instrumentation 验证，使用 API34 编译平台与 API30 `default;x86_64` 系统镜像；工作流不再创建或运行其他运行验证环境。
- `docs/build.md`：同步 API34 编译工具与 API30 验证环境说明。

命令：

