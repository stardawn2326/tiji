# 解题页编辑预览、图片处理与重复保存

日期：2026-09-30

## 本次改动

- 解题页的“编辑题目”弹窗增加“渲染预览”，使用现有 MathText / KaTeX 公式渲染组件。输入停顿 250ms 后更新预览，长内容可滚动查看。确认仍按修正题目重新解题，取消不改变原解答。
- 解题结果旁“添加图片”保留相册 / 拍照选择弹窗；取得图片后先进入“照片处理页”，多张图片按顺序处理。只有确认使用的图片才加入题目，确认后继续执行已有黑白净化处理。
- 照片处理期间禁止重复确认和退出，系统返回与页面返回执行一致的取消及临时文件回收。
- “保存为错题”在保存完成后可再次点击。再次保存当前解题记录会创建一条新的错题，按当前页面题目、答案、完整解析和图片保存；本轮已保存的记录再次另存无需重复确认。同一次正在进行的保存仍有防连点保护。
- 页面展示与保存共用内容快照，保存时不再用原始 V2 字段覆盖当前展示字段；解析中有意义的重复段落保持原样。保存不会重新解题，现有自动分类仅补充分类信息。
- 保存提示仍显示 3 秒后消失。其他页面的图片添加方式和错题库渲染缓存保持现有行为。
