# 题迹使用说明

## 安装

将 `outputs/apk/tiji-debug-v0.4.0.apk` 传到 Android 8.0 或更高版本设备，允许当前文件来源安装后完成侧载。

## 核心流程

1. 在首页点击“拍照录题”或“手工”进入录入页；拍照/相册载入后会立即进入图片处理区。
2. 图片处理支持“一键清晰化”（方向校正、灰度和对比度增强），也支持自由裁剪、旋转、增强、灰度化、黑白扫描、自动裁边和透视校正；每一步都可撤销，确认图片后才填写资料。
3. 拍照录题只填写标题、注释、科目、题目类型、分类/知识点和难度星级；保存时自动记录上传时间。
4. 需要解题时进入“AI 解题”，支持拍照、相册或纯文字输入。AI 结果会自动填充标题、题目、答案、解析、科目、类型和难度，所有字段都能人工修改；确认后点击“保存到错题”。
5. 在“错题”页按关键词或上传时间（今天/近 7 天/近 30 天）查询；点击“批量选择”可勾选题目并一键合并导出 PDF，PDF 包含题图、题目、答案、解析、注释和上传时间。
6. 在“复习”页先回忆题目，再显示答案并选择“忘记/困难/一般/简单”；设置页可配置每日数量和科目，未完成任务顺延到下一天。
7. 设置页可以导出不含 API Key 的 ZIP 备份。

## AI 配置

1. 打开“设置 → AI 兼容接口”。
2. 填写服务地址，例如 `https://api.openai.com/v1`，再填写支持图片输入的模型名称。
3. 填写自己的 API Key，点击“保存配置”，再点击“测试连接”。
4. 首次 AI 解题时阅读上传说明并确认；之后仍只有主动点击解题才会上传当前图片或文字。
5. 如需撤销授权，可在设置中关闭“允许主动使用视觉 AI”；也可随时清除密钥。

## 外观主题

应用固定使用蓝白配色，可选择跟随系统、浅色或深色显示模式。

## 隐私与 AI

错题数据库与图片默认保存在应用私有目录。服务地址和模型名称保存在 DataStore，API Key 经过 Android Keystore 加密；应用不会后台上传题目，只有用户主动点击 AI 解题并确认后才会把当前图片或文字发送给所配置的第三方服务。
