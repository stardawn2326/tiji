# Tiji 最终验收后收口改动详情

日期：2026-09-12
目标：按《Tiji_最终验收后下一步收口方案_2026-09-12.md》完成 v1.4G 核心流程收口。

## 执行边界

- 本轮聚焦错题录入、AI 解题、错题详情、复习、题库打印和 PDF 语义，不引入新的大型功能或新的 AI 协议。
- 只提交源码、测试和本变更文档；本地构建生成的 APK 不提交到 GitHub。
- 未重装 Android 系统、未创建新的 AVD，也未修改现有模拟器配置。

## 具体改动

### 1. PDF 练习/答案语义

- `HtmlPdfExportService` 的最终渲染只根据当前 `PdfExportOptions.includeSourceImages` 决定是否输出原题图片。
- `MistakeEntity.includeSourceImageInPdf` 保留为错题保存时的默认偏好，不再覆盖用户本次导出选择。
- `originalImagesOnly` 在关闭原题图片时不再产生图片-only 页面。
- 新增 instrumentation 测试覆盖：练习版隐藏答案与解析、答案版包含答案与解析，以及当前导出开关覆盖历史偏好。

### 2. AI 解题结果页

- 有图片时在输入区直接展示三种解题方式：视觉模型、OCR + 文本模型、视觉辅助 + 文本模型。
- 纯文本输入时不展示图片解题方式选择器；“更多设置”中保留 AI 配置、当前模型和配置入口。
- 结果区收敛为“题目 / 解析 / 答案”，一致性结果默认显示为“已完成检查”；只有警告或失败时展示问题明细和重新解题入口。
- 移除默认教学分步卡片和结果区重复的追问/历史入口，底部固定保留“继续追问”和“保存为错题”。最新对话只保留展开查看和复制回复。
- 删除导航层对已移除对话历史回调的依赖。

### 3. 录入方式切换

- 手动、拍照、AI 三种录入方式在存在未保存内容时显示“切换录入方式？”确认框。
- 确认文案为“切换后将清空当前未保存内容。”，提供“取消”和“继续切换”。
- 无未保存内容时直接切换，并清理当前模式不适用的草稿/识别状态。

### 4. 错题详情与复习打卡

- 底部主操作统一为“复习打卡”，不再直接写死“标记熟练”。
- 打卡弹窗提供“忘记 / 困难 / 掌握 / 熟练”四档，调用现有复习调度逻辑写入 mastery、reviewCount、lastReviewedAt、nextReviewAt 和 review_records。
- “加入/移出复习”继续放在右上角更多菜单，保持计划管理语义清晰。
- “我的答案、错因标签、我的总结”收进可展开的“更多信息”，默认优先呈现题目、正确答案和解析。

### 5. 复习流程

- “为什么今天复习”改为折叠的“到期复习”信息条，点击后才显示具体原因。
- 完成任一复习等级后保留短暂“已记录”状态，随后自动进入下一题；最后一道自动进入本次总结。
- 保留上一题/下一题作为恢复或人工操作兜底，不改变已有复习记录去重机制。
- 更新 focused review、重建恢复和题库发起复习测试，以适配自动流转。

### 6. 错题库打印入口

- 打印动作移到筛选结果数量同一行，显示为“打印 / PDF”。
- 打印动作与当前筛选后的错题数量相邻，避免用户误解打印范围。
- 无可打印错题时按钮保持禁用。
