## 执行边界

本轮只处理 UI 2.0 收口方案要求的测试契约和测试入口对齐。生产 UI、业务逻辑、数据模型和已冻结的纸张蓝 UI 结构保持不变。生产代码只增加 Compose `testTag`，不改变布局、文案、颜色、交互或业务行为。按验收要求未进行视觉检查，也未合并到 `main`。

## 代码改动

### 稳定筛选定位

- `app/src/main/java/com/tiji/mistakes/ui/library/LibraryScreen.kt`
  - 为四个掌握度选项增加 `library_mastery_option_0..3` 稳定 `testTag`。
- `app/src/androidTest/java/com/tiji/mistakes/LibraryFilterTest.kt`
  - 使用 `library_mastery_option_0` 定位“未掌握”，移除依赖重复文案索引 `[1]` 的脆弱选择器。

### 知识点测试 Host

- 新增 `app/src/androidTest/java/com/tiji/mistakes/KnowledgeTestHost.kt`。
  - 从真实 Room 数据库、`MistakeRepository` 和 `WeaknessCalculator` 加载知识点、关联错题、复习历史及统计结果。
  - 直接渲染生产 `KnowledgeDetailScreen`。
  - 为专项复习测试提供只存在于 androidTest 的 Host，使用真实 `MistakeViewModel`、真实 `ReviewSessionPlan` 和生产 `ReviewQuestionScreen`。
  - 不恢复已删除的 Library 知识点入口，不复制生产算法。

### 知识点详情与统计

- `app/src/androidTest/java/com/tiji/mistakes/KnowledgeDetailAnalyticsTest.kt`
  - 去除 Library/导航入口依赖。
  - 直接渲染真实知识点详情，验证 30 天内统计值为 `2`。
- `app/src/androidTest/java/com/tiji/mistakes/KnowledgeExplorerTest.kt`
  - 重命名为 `knowledgeDetailShowsOnlyRelatedMistakesForStablePoint`。
  - 直接渲染数学知识点详情，验证数学关联错题存在、物理同名标签错题隔离、移除的“查看相关错题”入口不存在。

### 专项复习与重建

- `app/src/androidTest/java/com/tiji/mistakes/FocusedReviewUiTest.kt`
  - 用真实知识点关联队列创建 `ReviewSessionSource.KNOWLEDGE_POINT` 复习计划。
  - 通过真实 `MistakeViewModel.startReviewSession` 进入生产复习问答与总结页面，保留手势、评分、总结和回到知识点详情的断言。
- `app/src/androidTest/java/com/tiji/mistakes/FocusedReviewRecreationTest.kt`
  - 公共 `openFocusedReview()` 改为使用真实知识点队列和测试 Host。
  - 保留 4 项 Activity 重建、答题状态、题目索引、总结恢复和重复评分幂等断言。

