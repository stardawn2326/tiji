# 题迹 UI 改动详情

日期：2026-09-10  
版本：`1.0.0` / `versionCode 114`

## 1. 改动目标

本次 UI 调整以设计规范中的 Soft Academic / Notion / Material 3 概念图为视觉基准：使用浅紫灰背景、白色内容面、靛蓝主色、紫色 AI 强调色、细边框和低层级阴影，形成更轻、更清晰的学习工作台。

本次范围以概念图和设计规范重新组织页面骨架、信息层级、导航文案和交互过渡，不以旧版页面结构作为约束。AI、数据、复习计划和图片处理等业务逻辑保持可用；科目标签由已保存数据动态生成，不再依赖固定科目图标或硬编码科目列表。

## 2. 主要改动

### 2.1 主题与设计令牌

- `Theme.kt` 增加显式字体层级：28sp 展示、24sp 一级标题、20sp 二级标题、16sp 三级标题、15sp 正文、13sp 辅助文字、12sp 标签、11sp 说明文字。
- 浅色主题使用规范中的 Soft Academic 色板：背景 `#F7F8FC`、卡片 `#FFFFFF`、主色 `#6366F1`、主色容器 `#EEF0FF`、正文 `#18181B`、次要文字 `#71717A`、边框 `#E4E4E7`。
- 深色主题使用对应的深色背景和高亮主色，保留正文、次要文字、分隔线之间的对比度层级。
- 新增 `TijiDimens`，统一页面内边距、区块间距、卡片间距、控件间距和圆角，遵循 4/8dp 间距节奏。
- 新增 `TijiSurfaceCard`，用于新的白色内容面卡片：1dp 细边框、16dp 圆角、低视觉噪声。
- 新增 `ConceptPageHeader`、`ConceptSectionHeader`、`ConceptTag`、`ConceptDashedDropZone` 和 `TijiStatusBadge`，统一页面标题、区块层级、动态标签、图片录入和掌握状态表达。

### 2.2 导航与动效

- 底部导航统一为设计规范中的五项：`首页 / 错题 / AI解题 / 复习 / 我的`。
- 五项底部导航均作为一级页面入口；错题详情、录入错题、复习日历、AI 历史和设置子配置等页面使用独立返回式顶部栏。
- 一级底部导航使用 180ms 淡入淡出，避免高频切换产生过度位移。
- 详情、录题、复习日历、AI 历史和配置等二级页面使用 220ms 横向滑入滑出，保持来源与去向的空间连续性。
- 新卡片内容变化使用 200ms 内容尺寸过渡，服务于展开、折叠和状态更新的可理解性。
- 动效仅用于反馈、状态提示和页面空间连续性；主要调整属性为透明度、位移和内容尺寸，避免长时间或装饰性动画阻塞操作。

### 2.3 首页

- 增加更清晰的问候区和今日复习主卡片。
- 今日复习卡片展示完成进度、待复习数量和主行动按钮。
- 学科概览改为由已保存数据驱动的横向卡片，窄屏首屏最多展示三个科目，提供数量与掌握状态的快速扫描。
- 增加薄弱知识点和最近错题区块，并统一使用新的表面卡片和状态标签。
- 学科卡片使用通用书本图标，不按科目名称映射硬编码图形；薄弱知识点展示数量、弱项百分比和进度条。

### 2.4 错题库

- 增加完整搜索提示文本、学科横向筛选标签和筛选对话框。
- 筛选行重组为概念图要求的 `知识点 / 掌握状态 / 难度 / 排序` 四个入口；知识点和排序使用下拉菜单，状态和难度使用筛选对话框。
- 搜索范围覆盖题目、我的答案、正确答案、解析、总结、标签、错因和 OCR 文本。
- 录入入口移到页面标题栏，避免悬浮按钮遮挡列表卡片。
- 错题列表改用新的 `ConceptMistakeCard`：科目作为动态文字标签展示，题目、摘要、掌握状态和复习信息分层排列，不再显示旧版科目符号。

### 2.5 错题详情

- 顶部增加学科、题型、日期和掌握状态元数据卡片。
- 题目图片、题目、我的答案、正确答案和解析区分为白色内容面卡片；已有笔记继续作为“我的总结”呈现。
- 新增“错因标签”多选 chips，并将“我的答案”和“我的总结”作为独立字段持久化；Room 数据库升级至 v9，兼容 v7/v8 数据。
- 底部固定操作改为“已掌握 / 稍后复习”和“查看完整解析”双行动布局。
- 增加“编辑错题”和“加入复习/移出复习”操作，并在复习统计卡片中呈现相关状态。
- 关键图标按钮补充内容描述，标题改为“错题详情”。

### 2.6 录入错题

- 入口改为 `拍照录题 / AI识题 / 手动录入` 三段式控件，与概念图保持一致。
- 上传区域使用虚线边界和明确的上传占位组件，相册/拍照动作直接收纳在上传区内；“记录信息”提前到补充图片之前，首屏层级与概念图一致。
- AI 识别期间保存按钮显示 `正在识别…` 并禁用，避免重复提交。
- 底部保存行动只保留主色高对比按钮，避免额外说明压住录入字段。

### 2.7 AI 解题与复习

- AI 解题内容区域使用分层卡片承载题目识别、解题思路和最终答案。
- AI 结果区增加边界与留白，减少与页面背景的混淆。
- 复习入口改为概念图式的任务页：标题、今日进度、复习节奏、首题任务卡和后续题目分层展示；无计划时显示轻量空状态和“开启复习计划”操作，不再使用大块禁用按钮占位。
- 复习详情页突出 `当前题号 / 总题数`，先呈现题目，点击“查看答案”后再展示答案与解析。
- 复习评分按单行四项排列，并展示“明天 / 3天后 / 7天后 / 14天后”等间隔提示；保留后端 `GOOD` 状态，界面显示为更直观的“会了”。

### 2.8 我的 / 设置

- 设置页面标题改为“我的”，更贴合底部导航语义。
- 设置卡片、空状态和复习进度卡片统一使用新的表面卡片样式。

## 6. 动效与可访问性检查结论

- 动效采用短时长、可理解的淡入和横向空间过渡，不使用 `scale(0)`、`transition: all` 或长时间阻塞式动画。
- 交互状态通过文字、图标、边界和颜色共同表达，不依赖单一颜色。
- 录入页、详情页的固定底部操作区增加滚动安全区；底部导航选中态使用主色容器，与概念图的轻量靛蓝强调一致。
- 新增/保留的控件继续使用 Android 原生 Compose 语义和内容描述；设备上的减弱动效、最大字体、横屏和深色主题仍需在模拟器启动后进行最终人工走查。
