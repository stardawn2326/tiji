## 1. 本轮范围

本轮只处理“设置”功能，目标是把原来的单体设置滚动页重构成可独立进入、可独立返回的真实页面。没有混入首页、错题库主体、复习执行页、PDF 打印流程、AI 解题结果页或拍照录入流程的重构。

同时处理了一个由设置入口迁移造成的导航关系：设置页不再承载“科目与知识点”入口，知识点浏览入口迁移到错题库一级页；知识点页面和错题关联逻辑本身没有删除或改写。

## 2. 重构前的问题

- `MyScreen.kt` 既承担设置首页，又承担设置分组入口。
- `SettingsScreen.kt` 约 729 行，把 AI、视觉辅助、OCR、复习计划、数据备份恢复、PDF 图片偏好、外观和关于内容放在同一滚动壳中。
- 原 `settings-detail/{section}` 路由只是改变同一滚动页的初始位置，不是按功能拆分的真实页面。
- `SettingsSection` 中还保留已经不应出现在设置首页的 `SUBJECT` 分支。
- 设置子页继续显示底部五项导航时，用户容易误以为自己仍停留在设置一级页面。

## 4. 功能迁移与保留情况

### AI 页面

- 保留 AI Profile 的新增、切换、保存和删除。
- 保留服务商预设、Endpoint、模型 ID、本机加密 API Key 和连接测试。
- 保留当前文本 Profile 与视觉辅助 Profile 的绑定入口。
- 保留 OCR 模型状态、下载、停止、更新和清理操作。
- 没有改变 AI 请求协议、响应结构或解题算法。

### 复习页面

- 保留复习计划开关、每日复习题数、复习科目、随机复习和星期分配。
- 保留 `DailyStudyPlanner`、`ReviewScheduler` 和复习记录写入关系。
- 保存后仍通过原有偏好和 ViewModel 回调更新运行时状态。

### 数据页面

- 保留本机数据导出、导出检查、导入合并、导入替换。
- 保留全量重置和复习数据重置，并维持二次确认弹窗。
- 保留 `BackupService` 的读写、校验和导入模式逻辑。
- 现有 `aiExcludeSourceImageByDefault` PDF 导出偏好迁移到“PDF 导出”区块，没有丢失。

### 外观与关于页面

- `ThemeMode` 和 `ThemePalette` 继续使用原有状态和持久化方式，仅改变承载页面。
- 关于页使用 `BuildConfig.VERSION_NAME` 显示当前版本，并明确本地优先和 AI 主动联网边界。

### 知识点入口

- 从设置首页删除“科目与知识点”行。
- 错题库一级页新增“知识点”操作入口，测试标识为 `library_open_knowledge`。
- 知识点列表、知识点详情、分析和错题关联导航保持原有实现。
- 已同步修改依赖旧设置入口的知识点和复习 UI 测试。
