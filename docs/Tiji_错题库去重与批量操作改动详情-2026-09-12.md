# Tiji 错题库去重与批量操作改动详情

日期：2026-09-12

依据方案：`Tiji_复习交互验收与下一步错题库去重方案_2026-09-12.md`

执行分支：`codex/v1.4f-ai-solve-core`

实施基线：`6c0d3027d336a34691fbaabc3fe8df5a2df3e429`

## 1. 本轮范围

本轮只处理 `LibraryScreen` 的错题库入口组织：

1. 删除普通列表结果区重复的“打印 / PDF”入口。
2. 保留批量选择模式中的打印、复习和删除能力。
3. 将批量选择状态与批量动作拆成上下两个职责层。
4. 不修改 PDF 生成服务、PDF 选项、预览、保存和系统打印链路。
5. 不修改数据库 schema、筛选/搜索/排序逻辑、复习调度或五个一级页面路由。

本轮启用已有 `tiji-api30.avd`，设备序列号为 `emulator-5556`，没有重装安卓系统或创建新的 AVD。

## 2. 具体 UI 改动

### 2.1 普通模式

`LibraryScreen.kt` 的结果统计行只保留：

```text
N 道错题
当前：科目（有筛选时显示）
```

删除了普通模式下的 `library_print_filtered` 按钮和“打印 / PDF”大按钮。这样打印不会与批量模式形成两套入口。

原有批量打印仍然可以通过：

```text
批量选择 → 选择题目 → 打印 → PDF options → 预览 → 保存 / 系统打印
```

### 2.2 选择状态 TopAppBar

进入“批量选择”后，顶部改为选择状态层：

```text
关闭（×）       已选择 N 道                    全选
```

- 关闭按钮退出选择模式并清空当前选择。
- `library_select_all` 保留全选/取消全选行为。
- 选择数量使用“已选择 N 道”表达，避免与普通结果数量混淆。
- 所有顶部操作保留可访问语义和至少 48dp 触控高度。

### 2.3 底部上下文操作栏

批量动作从 TopAppBar 移到底部独立操作栏，三个动作等宽排列：

```text
开始复习             打印             删除
```

- `library_start_selected_review`：沿用现有复习会话创建逻辑。
- `library_print_selected`：继续调用现有 `openPdfOptions(selectedIds)`。
- `library_delete_selected`：继续使用现有删除确认、软删除和 Snackbar 撤销流程。
- 未选择题目时三个动作禁用，避免无效操作。
- `BatchBarAction` 本身保持 48dp 高度，本轮无需扩大组件职责。

## 4. 自动化验收

新增：`app/src/androidTest/java/com/tiji/mistakes/LibrarySelectionActionsTest.kt`

覆盖：

- 普通模式不再出现 `library_print_filtered`。
- 进入选择模式后，TopAppBar、退出、全选和底部操作栏存在。
- 未选择题目时复习、打印、删除均禁用。
- 全选后三个批量动作均可用。
- 打印仍能打开 `pdf_export_options`。
- 删除仍能打开“删除选中的错题？”确认对话框。
- 退出选择模式后恢复普通列表状态。
