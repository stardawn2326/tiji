## 交付结论

本轮已完成方案要求的 AI 解题、错题保存、知识点规范化、复习到期、掌握统计和三日预览闭环。知识点去重采用显式别名和受限安全候选规则；每日复习只取纳入计划且已到期的错题。代码、单测、迁移测例、备份兼容和 API30 设备回归均已执行。

## 功能改动

### 知识点规范化与去重

- 新增 `KnowledgePointAliasEntity`、`KnowledgePointAliasDao`，为每个科目保存别名、规范化别名和旧 stableId。
- 新增 `KnowledgePointCanonicalizer`。精确规范名、已登记别名和方案内的“二重积分计算/二重积分的计算/计算二重积分”会指向“二重积分”。普通字符串不会通过删词或宽泛包含关系自动合并。
- `MistakeRepository.save`、`applyAiClassification`、批量保存和旧标签回填均在同一 Room 事务内同步结构化知识点并清理可证明的语义重复。
- 重复迁移按稳定 id 顺序执行：移动错题关系、重挂子节点、迁移别名、记录旧 stableId、删除重复节点，最后清理孤儿和非法父节点；重复执行结果不变。
- `legacy_tag_backfill_version` 提升为 2，已有安装会自动再执行一次幂等回填和去重。

### 首页掌握统计

- 首页改为只读掌握总览：错题总数、已掌握数量、掌握率和科目统计。
- 科目行可原地展开知识点统计，显示每个知识点的错题数、已掌握数和掌握率。
- 统计只使用活跃错题、最新复习评价和结构化交叉引用；同一道题通过多个别名只计一次。
- 掌握证据仍以最新 `GOOD`/`EASY` 复习评价为准，不把内部 mastery 数值直接当作掌握结论。

### 三日复习计划

- `DailyStudyPlanner` 删除薄弱补强和可选巩固的排程路径，只按 `inReviewPlan && nextReviewAt <= now` 取到期题目。
- 保留每日上限、科目偏好、科目轮转和确定性排序；知识点薄弱度只可用于分析展示，不再改变排程。
- 复习页新增明天、后天、大后天三个日期卡片，显示真实题目标题、科目、日期和题干摘要，可直接进入详情。
- 未来三日同样过滤删除、归档和退出计划的错题，并应用每日上限和稳定排序。
- 旧计划快照回退路径增加到期、未归档、未删除和仍在计划内的过滤，避免历史薄弱/可选条目重新进入最终排程。

### 备份与兼容

- Room schema 从 11 升至 12，新增 `knowledge_point_aliases` 表、唯一索引和外键级联；提供 11→12 迁移及 7/9/10→12 组合迁移出口。
- `.tiji` 备份 schema 从 3 升至 4，新增 `data/knowledge_point_aliases.json` 和别名计数；旧 schema 3、schema 2 和 legacy 备份仍可读取。
- 导入时先恢复知识点和别名，再恢复交叉引用；旧稳定 id 可通过别名解析。替换导入会同时清理旧知识点别名，导入完成后再次执行结构化同步和父节点清理。
- 未发现独立的复习提醒、WorkManager 或 Alarm 调度实现；AI/OCR 前台进度通知服务继续保留，用于正在执行的任务。
