# 项目总结：题迹 v0.4.0 录入分流与复习计划版

## 已完成

- 完成项目内 JDK 17、Android SDK API 35、Build Tools 和 Platform Tools 装载。
- 初始化 Kotlin/Compose 单模块工程，使用 Room、DataStore 与 MVVM 分层。
- 实现首页、错题库、录入、AI 解题、详情、复习、设置六类页面和底部导航。
- 实现手工录入、拍照/相册入口、私有图片复制、应用内图片处理和全文关键字搜索；移除低质量离线 OCR 入口及依赖。
- 实现软删除、复习反馈与间隔安排、PDF 导出、ZIP 备份、深色主题和 Keystore API Key 保存。
- 实现 OpenAI 兼容视觉识题和文字解题、连接测试、严格 JSON 字段校验、错误分级和首次上传隐私确认；AI 结果需确认后保存。
- 实现拍照后立即进入处理、一键清晰化（方向校正、灰度、对比度增强）、自由裁剪、旋转、增强、黑白扫描、自动裁边、透视校正和逐步撤销。
- 增加题目类型与上传时间字段及 Room 迁移；错题库支持按时间筛选、批量选择和带题图合并 PDF 导出。
- 拍照录题与 AI 解题分流；AI 自动生成标题、题目、答案、解析、类型并允许人工覆盖修改；难度改为可直接点击星级。
- 增加每日复习数量和科目设置及明日顺延预览；主题固定为蓝白；版本升级为 0.4.0。
- Debug APK 构建成功；lint 通过；6 个 JVM 单元测试通过（通过临时 ASCII 盘符映射规避 Windows 中文路径 worker 问题）。
