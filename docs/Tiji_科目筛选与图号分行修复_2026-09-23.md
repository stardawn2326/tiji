# 科目筛选与图号分行修复

## 改动

- 错题库科目筛选未选择时，按钮文案由“全部”改为“科目”。下拉菜单中的“全部”仍用于取消科目限制；其他筛选功能保留。
- 题目自动分行排除图号和公式引用，例如 `图(a)、(b)`、`图（c）`、`公式 (1) 和 (2)`，避免将其当成新的小题。
- 答案分行复用相同引用判断，避免将答案内的图号、公式编号切成独立答案。
- 真正的选择项、小题序号、答案序号继续分行，LaTeX 公式内容保留。
- 改动仅作用于显示排版，不改写已保存的题目或答案。题目 PDF 复用同一排版规则。
