## 实施范围

本轮只收口复习四档、确认规则、复习记录展示和错题卡状态来源。数据库中的 `ReviewGrade` 字符串以及 `mastery` 字段保持兼容，没有新增第五档、没有迁移历史记录、没有新增 AI 作答检查，也没有进行视觉验收。

## 已完成改动

### 四档文案与确认规则

- 统一 `FORGOT / HARD / GOOD / EASY` 的展示为“忘记 / 生疏 / 掌握 / 熟练”。持久化枚举字符串不变。
- “忘记”“生疏”“掌握”直接记录；只有“熟练”显示“确认熟练？”二次确认。
- 确认弹窗说明为“确认后将记录本次复习为‘熟练’。”，按钮为“取消 / 确认熟练”。取消不会写入记录、改变题目状态或进入下一题。
- 复习做题页和错题详情页都执行同一确认规则。
- 复习总结、复习日历、复习原因和详情历史统一通过 `ReviewGrade.label` 显示档位文案。

### 错题卡状态与真实记录

- 新增 `MistakeListItem(mistake, latestReviewGrade)` 读模型。
- 错题库一次性查询当前列表对应的最新 `ReviewRecord`，按 `reviewedAt`、`id` 稳定选择，避免每张卡单独查询。
- 状态显示规则固定为：
  - `reviewCount = 0`：`未复习`
  - 有复习次数且有最新记录：`复习 N 次 · 忘记/生疏/掌握/熟练`
  - 有复习次数但最新记录缺失：`复习 N 次`
- 错题库、复习题页、错题详情页、知识点详情关联错题卡均不再根据 `mastery` 推断“已掌握”等用户状态。
- 详情和知识点历史不再展示 `masteryBefore/masteryAfter` 数值，只展示复习档位和下次间隔。

### 首页进度

- 首页进度从“已掌握/掌握率”调整为“已复习/复习率”。统计基于实际复习记录或 `reviewCount`，不再使用 `mastery >= 3` 阈值。
- 各科行同步显示“已复习”数量，活动记录仍过滤删除和归档数据。

### 兼容边界

- `mastery` 字段、调度算法、备份字段和旧 `ReviewRecord.grade` 数据继续保留，未做数据库迁移。
- 错题库原有掌握筛选仍保留为兼容内部筛选；它不参与卡片状态展示。
