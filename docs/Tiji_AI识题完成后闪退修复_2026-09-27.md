# AI 识题完成后闪退修复

## 问题与原因

用户补充：手机上的闪退发生在 AI 识题返回结果后。此前处理的相机进程恢复问题没有覆盖这个触发点。

`NewCaptureScreen` 的识别结果确认弹窗在 `TijiDialog` 自带的纵向滚动容器内又嵌套了 `verticalScroll`。识别完成后弹窗开始测量，内外滚动层的高度约束冲突导致布局异常。

API 30 的真实界面回归测试在修改前失败，异常为 `IllegalStateException: layout state is not idle before measure starts`，栈经过 `DialogLayout.internalOnMeasure`。仅移除内部重复滚动层后，同一测试通过。

## 改动

- 移除识别确认弹窗正文的重复 `verticalScroll`，统一由 `TijiDialog` 提供滚动。
- 保留题目、答案、解析、图片、确认填入与取消操作，不修改识别请求、模型配置或返回内容。
- 新增 `AiRecognitionCompletionUiTest`，以持久化的识别完成结果进入实际录题页面，包含长解析，检查弹窗打开、确认填入、成功提示。

## 验证

- API 30：修改前同一测试失败；修改后 1 个测试通过，0 失败。
- 测试日志：`outputs/ai-recognition-before.log`、`outputs/ai-recognition-after.log`。
- `git diff --check` 通过。
- 回归使用本地构造的识别结果，不调用真实 AI 接口，不消耗模型额度。
- 未连接用户手机，因此不能将模拟器结果等同于用户手机复测通过。
