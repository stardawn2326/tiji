## 1. 本轮执行边界

本轮启用已有的 API 30 AVD `tiji-api30.avd`，不重装安卓系统、不创建第二套系统，也不改变 API 35 AVD。代码范围严格对应方案中的两个收口项：

1. 将设置首页从五个独立卡片收敛为普通列表；
2. 完成复习交互审查，在不改写复习状态机和算法的前提下补齐横向切题，并修复退出后无法继续当前会话的问题。

没有改动数据库 schema、复习调度算法、AI 请求协议、OCR 模型、PDF 导出协议或五个一级页面的导航结构。

## 2. 设置首页：从独立卡片改为普通列表

文件：`app/src/main/java/com/tiji/mistakes/ui/settings/SettingsHomeScreen.kt`

- 删除设置首页的 `SettingsHomeSection` 和单行卡片包裹层。
- 保留五个入口：AI 模型、复习计划、备份与恢复、显示模式与主题、关于题迹。
- 改为一个连续的 `LazyColumn`，入口之间使用横向分隔线。
- 每一行继续保持至少 64dp 的可点击高度，整行可点击，保留原有测试标识和状态摘要。
- 不改变五个设置子页的功能、数据读写和返回关系。

这样设置首页表达的是“功能入口列表”，子页面才承担具体设置内容；没有把设置子页重新塞回首页滚动容器。

## 3. 复习交互审查结论

### 3.1 现有状态链路

| 环节 | 当前实现 | 本轮处理 |
| --- | --- | --- |
| 计划来源 | 今日计划、知识点专项、错题库选择均生成 `ReviewSessionPlan` | 保留 |
| 会话状态 | `ReviewSessionController` 管理题目、`currentIndex`、已记录题目、总结状态 | 保留 |
| 持久化 | `MistakeViewModel` 通过 `SavedStateHandle` 保存活动会话 | 保留 |
| 题目切换 | `ReviewQuestionScreen.moveBy()` 统一处理上一题/下一题 | 横滑复用该入口 |
| 评分写入 | 原有 `viewModel.review()`、单题去重和复习记录写入 | 保留 |
| 评分后推进 | 记录成功后保持 520ms 自动推进，最后一题进入总结 | 保留 |
| 返回行为 | 原先导航层返回时直接清除统一会话 | 改为返回但保留会话 |

历史审查了公开基线 `d816dafe`、复习状态机合入点 `32c09b3` 和本轮基线。历史版本没有发现复习页面已有的横向 Pager 或左右滑动切题实现；现有 `pointerInput` 只用于拍照裁剪和图片预览。因此本轮横滑是复用现有状态机的增量交互，不是恢复一段不存在的旧实现。

### 3.2 返回与恢复修复

文件：`app/src/main/java/com/tiji/mistakes/ui/navigation/TijiNavGraph.kt`、`app/src/main/java/com/tiji/mistakes/ui/review/ReviewQuestionScreen.kt`

- 题目页顶部返回只退出当前题目页面，不清除统一复习会话。
- 用户从今日复习题目返回复习一级页后，仍可看到“继续今日复习”，并恢复原题目索引和已答状态。
- 复习总结页退出时仍清除已完成会话。
- “移出复习计划”仅在计划更新成功后清除会话，避免异步更新失败时丢失当前会话。
- 非今日计划的专项会话在明确移除当前题目后仍按原有流程结束，不改变评分和调度逻辑。

### 3.3 横向切题

文件：`app/src/main/java/com/tiji/mistakes/ui/review/ReviewQuestionScreen.kt`

- 在题目内容 `LazyColumn` 上增加水平拖动识别。
- 向左滑动进入下一题，向右滑动返回上一题。
- 触发阈值为 72dp，避免轻微触摸或纵向滚动误触发。
- 评分提交中或自动推进等待中不响应横滑。
- 继续保留底部“上一题 / 下一题”按钮，横滑不是唯一入口。
- 增加可见提示“左右滑动切题，也可使用底部按钮”。
- 增加 `review_previous`、`review_next`、`review_swipe_hint` 测试标识，便于后续验收和无障碍回归。

同时在 `FocusedReviewUiTest.kt` 增加左右滑动前进、后退断言，在 `ReviewQuestionUiTest.kt` 增加退出后继续会话断言。
