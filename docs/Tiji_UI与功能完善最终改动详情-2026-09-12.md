# 题迹 Tiji：UI 与功能完善最终改动详情

日期：2026-09-12
依据：`Tiji_UI与功能完善_含PDF纸质打印核心方案_2026-09-11.md`
范围：在现有 Jetpack Compose Android 应用中，完成方案要求的 PDF / 纸质练习核心路径，并收口保存语义与本地优先体验。

## 一、这次实际完成的用户路径

```text
错题库 / 今日复习 / 知识点详情 / 单题详情
        ↓
打印 / PDF
        ↓
选择练习版或答案版
        ↓
本地生成 PDF
        ↓
预览
        ↓
保存 PDF 或系统打印
```

所有 PDF 生成、预览和保存都在设备本地完成，不需要网络，也不会把错题内容发送给 AI 服务。

## 二、PDF 入口与页面改动

### 1. 错题库

- 在错题库主内容区增加“打印当前 N 道错题”，直接使用当前搜索、科目、知识点、掌握度、难度和标签筛选结果。
- 批量选择工具栏增加“打印 / PDF”，与“开始复习”“删除”处于同一级。
- 导出范围在入口处冻结为题目 ID，生成预览和系统文件选择器返回后仍按 ID 恢复，避免筛选变化导致错题错配。

### 2. 今日复习

- 将“打印今日复习”提升到复习题列表之后的直接入口。
- 不再把今日复习 PDF 放在“更多复习工具”里。
- 导出使用当前复习计划队列，和实际练习顺序一致。

### 3. 知识点 / 专项

- 知识点详情增加“打印纸质练习”，范围只包含当前知识点的关联错题。
- 与“开始专项复习”并列，支持练习版和答案版。

### 4. 单题详情

- 在右上角更多菜单增加“打印此题”。
- 单题沿用同一套模板选择、PDF 预览、保存和系统打印流程。

## 三、PDF 模板与输出规则

新增 `PdfTemplate` 和 `PdfExportOptions`，主入口只暴露两个核心模板：

### 练习版

- 包含题号、题目标题、科目 / 题型、题目文字、可选原题图片和答题留白。
- 不包含答案、解析、掌握状态、复习历史、AI 信息和内部标签。
- 默认 A4 纵向、标准答题留白。

### 答案版

- 前半部分保留题目，便于先独立完成。
- 后半部分新起一页，集中输出“参考答案与解析”。
- 支持答案文字、解析文字、答案图片、解析图片以及结构化答案 / 解析图片。

### 图片、公式和分页

- 继续复用现有 KaTeX + WebView 离线渲染链路，没有引入联网服务或重写 PDF 引擎。
- 原题图片默认保持比例，不拉伸；页面宽度超出时缩放，纵向内容按题目单元分页。
- 普通题目图片的打印上限调整为 82mm，避免照片被压缩得过小；旧版“仅原图”设置仍保留并只作用于练习版。
- PDF 页面固定为 A4 595 × 842pt，页面背景始终为打印友好的浅色，不跟随应用深色主题。
- 公式与中文文字继续使用已有排版与转义逻辑，避免 HTML 注入、公式截断和中文乱码。

## 四、预览、保存和系统打印

- 新增模板选项对话框：选择练习版 / 答案版、是否包含原题图片，再生成预览。
- 预览页显示模板、题目数和页数，并提供“保存 PDF”“系统打印”两个动作。
- “保存 PDF”使用 Android `CreateDocument`，最终写入仍走本地预览文件；用户取消文件选择时预览不会丢失。
- “系统打印”调用 Android `PrintManager`，打印内容与预览内容相同；没有打印服务时显示明确错误，不影响保存 PDF。
- 预览文件只放在应用缓存的 `pdf-previews` 目录，完成保存后成功清理；不会把构建产物或测试图片带入源码仓库。

## 五、保存语义与录题体验

## 七、交付边界

- 本次只提交源码和本改动详情 Markdown，不提交 APK、缓存、模拟器数据或测试生成图片。
