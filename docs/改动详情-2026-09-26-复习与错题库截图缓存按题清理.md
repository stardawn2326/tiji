# 复习与错题库截图缓存按题清理

## 行为

- 复习首页仅“接下来”的题目预览复用公式排版截图；当前题卡和做题页仍走实时渲染。
- 错题库标题和题目截图、复习“接下来”截图分别绑定错题 ID。题目内容、主题、尺寸变化会产生新的缓存键。
- 成功记录某题复习后，只清理该题“接下来”的内存和磁盘截图。单题删除、批量删除、永久删除后，清理对应题目的错题库和复习截图；清除全部学习数据时清空截图缓存。
- 缓存代次阻止删除或复习完成前启动的截图任务，在操作完成后把旧图写回缓存。既有未标记题目 ID 的旧磁盘截图在首次缓存访问时清理，因此升级后首次遇到公式卡片需重新生成一次截图。
- 内存截图缓存上限 20 MiB，应用私有磁盘缓存上限 128 MiB；截图不写入题库或备份。
