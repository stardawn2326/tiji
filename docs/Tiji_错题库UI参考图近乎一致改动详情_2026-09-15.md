# 题迹错题库 UI 参考图对齐改动详情

日期：2026-09-15
目标：在不改变错题库既有功能逻辑的前提下，将错题库页面的结构、间距、颜色、卡片层级和操作栏调整为接近验收参考图。

## 参考与范围

- 参考图：`C:\Users\23260\.codex\attachments\fc02d295-2504-4f91-b413-d35802aa852d\image-1.png`
- 本次范围：错题库页面及其错题卡、筛选区、批量操作区、页面导航容器。
- 运行验证环境：现有 `tiji-api30`，序列号 `emulator-5554`，Android API 30。没有创建或使用 API 35 环境。

## 视觉与结构改动

- 错题库改为独立的浅蓝灰页面背景，页面顶部使用返回、标题和“录入错题”入口组成的轻量页头。
- 搜索框改为圆角白色输入框，保留原有题目、知识点和标签搜索入口。
- 筛选区改为紧凑的圆角筛选项，保留科目、知识点、掌握状态、难度、排序和列表视图层级。
- 错题数量与“选择”入口放在列表标题行，批量选择后显示底部操作栏。
- 错题卡改为白底、细描边、轻圆角和紧凑内边距；题目标题、题干、科目/知识点/难度标签和相对日期按参考图层级排列。
- 题目标题右侧增加三点视觉入口；图片题保留“图片题目，打开查看原图”的原有兜底文案。
- 选择态使用浅蓝底色和主题色描边；复习、打印、删除操作使用清晰的主次和危险色区分。
- 错题库页面移除底部全局导航栏，返回入口回到首页；其他页面导航和业务回调不变。

## 功能逻辑保持

- 搜索仍由 `MistakeViewModel.searchQuery` 驱动，题目标题、题干、知识点和标签的查询链路保持不变。
- 科目、知识点、掌握状态、难度和排序仍使用原有筛选状态及 `MistakeOrder` 计算路径。
- 点击错题卡仍进入原有详情页；选择态仍只切换选中集合。
- 批量加入明日复习、批量打印/PDF 预览、批量编辑、删除与撤销仍调用原有 ViewModel、导出服务和导航回调。
- 选择态左侧复选框保留独立触摸区域，卡片覆盖点击层只负责把普通点击转交原有 `onOpen`/选择回调。
