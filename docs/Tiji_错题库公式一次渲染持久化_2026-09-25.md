# 错题库公式图片缓存与返回位置修复（2026-09-25）

## 改动

- 错题库卡片的题目和标题以公式排版后的静态图片显示。只有冷缓存首次遇到某条公式时，才会启动 KaTeX/WebView 并生成截图。
- 每次组合先查内存截图缓存，未命中再异步查应用私有磁盘缓存；任一缓存命中就直接显示截图并提前返回，不创建 WebView。卡片的延迟渲染节流只影响冷缓存首次生成，不会挡住已缓存截图。
- 只有页面明确报告 KaTeX、字体和公式装饰已完成，且测量出的高度、滚动高度、宽度连续三次一致后，才允许生成卡片图片。Compose 视图完成对应高度布局后再截取；条件未满足或图片尺寸超过上限时继续保留 WebView 显示，不使用未完成画面。
- 同一运行期间的图片缓存限制为 20 MiB；应用私有磁盘缓存上限为 128 MiB，并按最近访问时间淘汰。缓存按完整渲染 HTML 内容计算键值，主题颜色、字号或视口变化会生成不同缓存项。
- 首页、错题库、AI 解题、复习、设置和知识点列表的 `LazyListState` 提升到导航图外，打开二级页返回时复用原列表状态。错题库进入详情或录题页时额外记录首个可见条目及偏移，在父列表重新挂载后恢复；点击底部一级页面仍回到顶部。
- 保存状态的键从固定路由名改为“路由名 + back stack entry ID”，避免快速切换时转场中的同路由页面短暂共用同一键。
- 底部导航去重改为读取 `NavController` 当前 entry 路由，避免依赖重组前可能过期的 `route` 状态。
- 2026-09-26：错题库题目正文改用与复习卡片一致的正文色；颜色参与截图缓存键，旧的浅色截图不会继续命中。
