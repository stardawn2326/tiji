# 题迹 UI 2.0 最终收口改动详情

本轮依据 `Tiji_UI2_验收与下一步最终收口方案_2026-09-12.md` 执行，范围限定为现有 UI 的最终精简、蓝色统一和难度映射。用户要求直接执行、安装模拟器并推送 GitHub，因此没有新增确认环节。

分支：`codex/ui-2.0-paper-blue`  
远程：`https://github.com/stardawn2326/tiji.git`

## 已完成

### 四档难度

- 在 `ui/common/Formatting.kt` 集中定义四档选项：简单、中等、困难、极难。
- `DifficultyPicker` 改为四档分段选择，移除五颗星交互。
- 错题卡、错题库筛选、详情编辑和保存面板共用同一套映射。
- 持久化仍使用原有 `Int difficulty`：`0` 显示“未设置”，`1` 至 `4` 显示四档，旧值 `5` 按“极难”显示并参与“极难”筛选；未做数据库迁移或旧数据批量改写。

### 错题卡与错题库

- 错题卡移除知识点名称、知识点关联文字和旧 `tags` 展示。
- 错题卡保留科目、题型、掌握状态、难度、题目和复习/更新时间信息。
- 搜索框文案简化为“搜索错题”。
- 错题库主界面移除重点知识点区、知识点库入口、知识点筛选 Chip、知识点下拉菜单及旧标签筛选；顶部只保留搜索、科目、掌握状态、难度和排序。
- 知识点实体、关联表和知识点详情流程保留；从知识点详情返回错题库时仍支持底层稳定筛选，不在错题库主界面展示知识点字段。

### 录题、编辑与保存

- 录题和编辑主流程隐藏知识点/标签输入、我的总结和错因选择。
- 保存面板移除知识点输入、本地知识点建议及解释性说明。
- 既有 `tags`、`note`、`errorReason` 值仍保存在状态和保存对象中；编辑旧题时不会因字段隐藏而主动清空。
- 标题、我的答案、题目、正确答案、解析、科目、题型、难度和图片链路保持原有行为。

### 详情页与文案

- 删除“更多信息”折叠层、错因展示和我的总结展示。
- 有内容的“我的答案”直接作为内容区显示。
- 题目、答案、解析和复习记录保留；移除无操作意义的解释性副文案。
- 复习掌握度弹窗移除重复说明文字，保留真实记录中的加载状态。
- 首页快捷入口移除说明副标题，首页各科错题仍为纵向长条。

### 蓝色统一

- `TijiSubjectColors` 不再按科目返回多色，普通学科强调统一使用主题 `primary`。
- 题型、难度、AI 结果等普通强调改用 `primary` / `primaryContainer` 层级。
- 删除操作和真实错误状态继续使用 `error` 语义。

## 保留范围

没有修改 AI 三种模式业务路由、AI 协议、复习算法与滑动逻辑、PDF 服务、数据库 schema、备份格式、Room DAO、知识点底层数据或图片存储协议。旧难度 5、旧标签、旧笔记和旧错因只改变可见展示，不做数据清理。
