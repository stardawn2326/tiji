# Tiji 知识点加载、拍照录题与题目 PDF 调整 — 2026-09-23

## 改动

- 知识点详情按 stableId 记住关联题目与复习记录 Flow，避免每次重组重新创建数据库订阅；最近复习状态映射按来源缓存。
- 知识点详情卡片关闭尺寸动画，减少数据到达时重复测量布局。无前后帧率基准，实际流畅度仍需验收。
- 打印入口只提供题目 PDF，默认不包含原图；仍可主动开启“包含原题图片”。所有打印入口不再从旧偏好默认启用原图。必要的结构化题目图仍保留。
- 拍照录题直接显示题目、答案、解析三张独立卡片。题目必填，答案、解析可选；各卡片支持拍照和相册，已有图片可重新处理。题目继续支持多图排序。
- 界面“正确答案”统一为“答案”，不修改用户已保存的文本。
- 错题详情的题干使用较小的正文规格，公式随文字同步缩小。
- 错题卡左上依次显示科目、题型、难度，右上显示复习状态；底部知识点不再重复题型。
- 错题库第三个筛选入口由“掌握”改为“状态”，筛选语义不变。
