# 题迹 Android 错题本——完整计划清单

> 版本：v1.0
> 日期：2026-08-07
> 状态：阶段 A 与阶段 B 核心闭环已完成，阶段 C-E 待迭代
> 项目：Project-004-题迹错题本

## 1. 产品结论

- [x] 产品名称暂定为“题迹”。
- [x] 面向个人使用，不注册账号，不建立身份档案。
- [x] 离线优先；没有网络和 AI API 时，核心错题管理功能仍可使用。
- [x] 最低支持 Android 8.0（API 26）。
- [x] 首要交付物为可直接安装的 APK，同时保留完整源码与构建说明。
- [x] 默认简体中文，界面采用简洁卡片式设计。
- [x] 不建设自有服务器，不收集用户账户和个人资料。

## 2. 成功标准

- [ ] 用户可在 30 秒内通过拍照或相册新建一道错题。
- [ ] 一道错题可完整保存题目照片、答案照片、OCR 文本、解析、分类和自定义字段。
- [ ] 普通中英文 OCR 可离线运行；OCR 失败不阻止手工录入和保存。
- [ ] 用户配置兼容 API 后，可完成视觉识题、自动分类、答案与解析生成。
- [ ] 支持按关键词、科目、章节、知识点、标签、错因、难度和掌握状态查找。
- [ ] 支持每日复习、间隔重复和本地提醒。
- [ ] 可导出 PDF 错题册、无答案练习卷、答案册和完整 ZIP 备份。
- [ ] ZIP 备份可在清空数据后的同版本应用中恢复。
- [ ] APK 可在至少一台 Android 8.0+ 真机或模拟器上安装、启动和完成核心流程。
- [ ] 用户数据和 API Key 不写入日志，不硬编码进源码或 APK 配置。

## 3. 功能范围

### 3.1 首页

- [ ] 展示今日待复习数量、错题总数、本周新增和掌握率。
- [ ] 提供“拍照录入”“相册导入”“手工录入”“开始复习”快捷入口。
- [ ] 展示最近错题、薄弱知识点和复习进度。
- [ ] 支持用户拖动调整首页模块顺序，并可隐藏模块。
- [ ] 空状态提供清晰的新手指引。

### 3.2 错题采集

- [ ] 使用 CameraX 拍摄题目照片。
- [ ] 从系统照片选择器单张或批量导入图片。
- [ ] 支持分别添加题目图、答案图和补充图片。
- [ ] 支持裁剪、旋转、透视校正和压缩。
- [ ] 支持连续录入：保存后直接进入下一题。
- [ ] 支持纯文本手工录入，不强制添加图片。
- [ ] 保存草稿，异常退出后能够继续编辑。
- [ ] 图片仅复制到应用私有目录，避免依赖原相册文件长期存在。

### 3.3 OCR 与内容识别

- [ ] 用 ML Kit 完成中文、英文及数字的离线文字识别。
- [ ] 保存原始 OCR 结果和用户修订文本，不因重新识别覆盖人工修改。
- [ ] 识别结果进入可编辑文本框，并标示识别状态和失败原因。
- [ ] 可选调用视觉 AI 识别数学公式、表格、图形题、题目结构和选项。
- [ ] AI 返回内容使用严格 JSON 结构并进行字段校验。
- [ ] AI 失败、超时或返回格式错误时保留原图和本地 OCR，可重试或手工编辑。
- [ ] 同一图片使用内容摘要缓存 AI 结果，减少重复请求。

### 3.4 错题编辑与详情

- [ ] 字段包括：题目、答案、解析、个人笔记、科目、年级、章节、知识点、标签、错因、难度、来源、掌握状态。
- [ ] 支持多个题目图片、答案图片和补充附件。
- [ ] 支持编辑、复制、收藏、归档、软删除和恢复。
- [ ] 支持上一题/下一题浏览。
- [ ] 记录创建时间、修改时间、最近复习时间、下次复习时间和复习次数。
- [ ] AI 生成内容必须明确标注，可独立重新生成，用户确认后再保存。

### 3.5 分类、自定义和检索

- [ ] 内置常用科目，同时允许新增、改名、排序、隐藏和设置颜色图标。
- [ ] 章节与知识点支持层级结构。
- [ ] 标签、错因和来源可自由维护。
- [ ] 自定义字段支持文本、数字、单选、多选、日期和开关类型。
- [ ] 自定义题目模板可指定默认字段、科目、标签和录入布局。
- [ ] 全局搜索覆盖 OCR 题目、答案、解析、笔记和标签。
- [ ] 多条件组合筛选并支持保存常用筛选器。
- [ ] 排序支持创建时间、修改时间、难度、复习时间和掌握程度。

### 3.6 AI 设置与解题

- [ ] 采用 OpenAI 兼容接口配置：服务地址、API Key、模型名称。
- [ ] 提供常见服务配置模板，但不承诺第三方服务持续免费或可用。
- [ ] 支持测试连接，并给出可理解的鉴权、额度、网络和模型错误。
- [ ] 可配置功能开关：视觉识题、自动分类、解题、解析、相似题建议。
- [ ] 可预览将要上传的图片与文本；首次上传前展示隐私确认。
- [ ] API Key 使用 Android Keystore 保护的本地加密存储。
- [ ] 日志、导出、备份和崩溃信息中排除完整 API Key。
- [ ] 设置页提供删除密钥和清除 AI 缓存操作。
- [ ] 不在首版内置本地大语言模型，避免 APK 体积、性能和兼容性失控。

### 3.7 复习系统

- [ ] 掌握状态：未掌握、学习中、已掌握。
- [ ] 基于 SM-2 思路安排下次复习，并允许用户手动修改日期。
- [ ] 每次复习提供“忘记、困难、一般、简单”四档反馈。
- [ ] 支持按科目、知识点、标签和错因创建专项复习。
- [ ] 支持顺序、随机和仅看题目三种复习模式。
- [ ] 答案和解析默认折叠，用户作答后揭示。
- [ ] 记录复习历史、连续学习天数和掌握率趋势。
- [ ] 使用 WorkManager 和系统通知发送本地提醒。
- [ ] 用户可设置提醒时间、每日题量、休息日并完全关闭通知。

### 3.8 PDF、练习卷与备份

- [ ] 按筛选结果生成 PDF 错题册。
- [ ] 生成隐藏答案的练习卷和单独答案册。
- [ ] PDF 可设置纸张、边距、每页题数、图片尺寸、标题和是否显示元数据。
- [ ] 通过 Android 系统分享和存储框架保存文件，不申请广泛存储权限。
- [ ] 完整备份采用 ZIP，包含数据库快照、图片、附件和版本清单。
- [ ] 备份不包含 API Key。
- [ ] 导入前检查版本、文件完整性与可用空间。
- [ ] 恢复前自动创建当前数据安全备份；支持合并或覆盖两种模式。
- [ ] 覆盖恢复必须二次确认，失败时回滚原数据。

### 3.9 外观与设置

- [ ] 支持跟随系统、浅色和深色主题。
- [ ] 支持自定义主题色、字号和列表密度。
- [ ] 支持首页模块排序和显示开关。
- [ ] 支持图片质量、默认科目、默认模板和连续录入设置。
- [ ] 支持数据统计、存储占用、缓存清理和回收站保留天数设置。
- [ ] 提供隐私说明、AI 数据说明、开源许可和应用版本信息。

## 4. 页面与导航结构

- [x] 底部导航：首页、错题、复习、设置。
- [ ] 首页：数据概览、快捷录入、今日复习、最近错题、薄弱点。
- [ ] 错题页：搜索栏、筛选器、列表/网格切换、批量操作。
- [ ] 采集流程：来源选择 → 图片处理 → OCR/AI → 编辑确认 → 保存。
- [ ] 详情页：题目 → 作答/答案 → 解析与笔记 → 分类信息 → 复习历史。
- [ ] 复习页：今日计划、专项复习、统计、提醒设置。
- [ ] 设置页：外观、自定义分类、AI、导入导出、数据与隐私、关于。
- [ ] 返回、取消和异常退出均不得静默丢失未保存内容。

## 5. 数据模型

- [x] `Mistake`：错题主体、文本内容、状态、难度、收藏、归档及时间字段。
- [ ] `Attachment`：题目图、答案图、补充图，记录本地路径、摘要、顺序和尺寸。
- [ ] `Subject`：科目及用户排序信息。
- [ ] `KnowledgeNode`：章节/知识点树。
- [ ] `Tag`、`MistakeTagCrossRef`：标签与多对多关系。
- [ ] `ErrorReason`：错因字典。
- [x] `ReviewRecord`：复习反馈、间隔、前后掌握状态和时间。
- [ ] `CustomFieldDefinition`、`CustomFieldValue`：自定义字段定义与值。
- [ ] `EntryTemplate`：录入模板及默认配置。
- [ ] `SavedFilter`：保存的筛选条件。
- [ ] `AppPreference`：非敏感偏好。
- [ ] 敏感 AI 配置单独进入加密存储，不进入 Room 数据库或普通备份。
- [ ] 为搜索字段建立 Room FTS 索引，为筛选和复习时间建立数据库索引。

## 6. 技术方案

- [x] 语言：Kotlin。
- [x] UI：Jetpack Compose + Material 3。
- [x] 架构：单 Activity、MVVM、Repository、Use Case 分层。
- [ ] 依赖注入：Hilt。
- [x] 本地数据库：Room + FTS。
- [ ] 图片：CameraX、系统 Photo Picker、Coil；编辑使用稳定的本地图片处理方案。
- [ ] 离线 OCR：Google ML Kit Text Recognition。
- [ ] 网络：OkHttp + Kotlin Serialization，统一兼容 OpenAI 风格请求。
- [ ] 后台任务：WorkManager。
- [x] 设置：DataStore。
- [x] 密钥保护：Android Keystore + 加密封装。
- [x] 导出：Android PdfDocument 或成熟 PDF 库；ZIP 使用标准流式压缩。
- [ ] 最低 SDK 26；目标 SDK 使用构建时稳定的最新正式版本。
- [ ] 依赖版本统一写入 Gradle Version Catalog，并锁定可复现版本。

## 7. 工程结构

- [ ] `app`：应用入口、导航和资源。
- [ ] `core:model`：领域模型。
- [ ] `core:database`：Room、DAO、迁移。
- [ ] `core:data`：仓库与数据源。
- [ ] `core:ui`：主题和通用组件。
- [ ] `core:ocr`：OCR 抽象及 ML Kit 实现。
- [ ] `core:ai`：AI 兼容客户端、协议、校验和缓存。
- [ ] `feature:home`、`feature:capture`、`feature:library`、`feature:review`、`feature:settings`、`feature:export`。
- [ ] 若模块化明显拖慢首版交付，可先采用单模块按包分层，但保持边界可拆分。

## 8. 隐私与安全

- [ ] 默认所有错题、图片、OCR 和复习记录仅保存在应用私有目录。
- [ ] 只有用户主动触发 AI 功能时才联网上传指定内容。
- [ ] 首次 AI 上传前明确说明第三方服务会收到哪些数据。
- [ ] 网络请求日志默认关闭正文，并脱敏 Authorization 头。
- [ ] 使用 HTTPS；自定义 HTTP 地址需警告并默认拒绝明文传输。
- [ ] API Key 输入框默认隐藏，剪贴板和截图风险提供提示。
- [ ] 不申请联系人、位置、麦克风等无关权限。
- [ ] 相机权限按需申请；相册优先使用无权限的系统照片选择器。
- [ ] 数据删除包括数据库记录、关联附件、缩略图和 AI 缓存；先进入回收站。
- [ ] 备份与 PDF 由用户明确选择保存位置。

## 9. 错误处理与边界情况

- [ ] 无网络、API 超时、限流、余额不足、模型不支持图片时均给出明确处理建议。
- [ ] OCR 模型不可用时允许下载/重试或切换手工录入。
- [ ] 低存储空间、大图、损坏图片和批量导入中断时不损坏已有数据。
- [ ] 应用被系统回收后恢复采集草稿。
- [ ] 数据库迁移失败时禁止破坏性清库，并提供导出诊断信息。
- [ ] PDF/ZIP 生成采用流式处理，避免一次加载全部原图导致内存溢出。
- [ ] 重复图片通过摘要提示，但允许用户确认后继续保存。
- [ ] 删除科目、知识点、自定义字段前显示影响范围并提供迁移目标。

## 15. 主要风险与控制

| 风险 | 影响 | 控制方案 |
| --- | --- | --- |
| 云端 AI 无法保证免费 | 用户可能产生调用费用或服务不可用 | BYOK、费用提示、可关闭 AI、离线核心闭环 |
| 数学公式离线 OCR 准确率有限 | 复杂题识别不完整 | 保留原图、人工编辑、可选视觉 AI |
| 图片和备份占用空间较大 | 存储增长、导出失败 | 压缩、缩略图、占用统计、流式导出、空间预检查 |
| 第三方兼容接口格式不完全一致 | AI 请求或 JSON 解析失败 | 适配层、连接测试、严格校验、原始错误摘要和重试 |
| Android 版本和厂商差异 | 相机、通知、文件选择行为不同 | 使用官方 API、多个系统版本测试、降级路径 |
| 签名密钥丢失 | 后续无法覆盖升级正式 APK | 交付时单独备份并记录保管说明，不进入源码仓库 |
