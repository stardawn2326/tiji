# Tiji

题迹错题本是一款面向 Android 的错题整理、复习和 AI 辅助解题应用。

## 功能

- 错题录入：相册、拍照、图片裁切与清晰化、文本和公式编辑、星级难度、分类和标签。
- 公式排版：题目、答案、解析和 AI 解答内置 KaTeX，行内公式与中文正文垂直居中，独立公式自动居中；公式内部使用半角 LaTeX，变量斜体，函数名、运算符和求和/积分符号正体，分式保持原有 `\\displaystyle` 比例，不缩小分式内容。
- 题目内容标点：题目显示和 PDF 导出使用中文正文全角标点，句末使用全角实心句点 `．`；公式内部不写中文全角标点；条目编号和选项使用半角括号。导航、按钮和普通提示文本保持原有显示规则。
- AI 解题：用户确认图片后才开始；支持后台继续、停止、重新解题、追问和历史对话；退出应用后清理未完成内容。
- 错题库：搜索、筛选、批量选择、详情编辑、删除撤回、最近 3 天错题。
- 复习：按科目安排、今日复习、掌握状态逐题记录、日历查询、全部完成后打卡。
- PDF：错题和复习均可预览并导出题目版或答案解析版；正文与公式采用 12pt，作答区至少三行且不显示横线。
- 数据迁移：导出可由应用重新读取的 `.tiji` 备份；新版本可导入旧版本数据，API Key 不写入备份。
- 导航：底部导航始终返回对应一级页面，二级页面不会阻塞切换。

## 技术栈

- Kotlin、Jetpack Compose、Material 3
- Room、DataStore、Android Keystore
- KaTeX、Android WebView/PDF、ZIP
- OpenAI 兼容视觉接口和本地 OCR 组件

最低系统版本：Android 8.0（API 26）。

## 构建

使用 Android Studio 打开项目，并配置本机 Android SDK。也可以在 Windows PowerShell 中执行：

```powershell
.\gradlew.bat assembleDebug
```

`local.properties` 只用于记录本机 SDK 路径，不应提交到仓库。Release 签名配置使用本地 Gradle 属性或环境变量，签名文件和密码不会进入仓库。

## 目录

- `app/`：Android 应用源码和测试。
- `docs/`：项目说明和开发文档。
- `tools/`：应用使用的 OCR 组件源码。

本仓库不包含本地缓存、构建输出、过程日志或 `local.properties`。
