# 题迹 · Tiji

题迹是一款 Android 错题整理与复习应用。将纸上的题目、答案和解析保存到自己的错题库，用 AI 辅助识别与解题，再通过每日复习和纸质练习巩固知识。

## 三种方式录入错题

| 录入方式 | 可以做什么 |
| --- | --- |
| **照片录题** | 拍照或从相册选择题目、答案、解析图片；只需提供题目，答案和解析可选。 |
| **AI录题** | 识别图片中的题目、公式、答案与解析，整理分类信息，检查和编辑后保存。 |
| **文字录题** | 手动输入题目、答案和解析，也可以补充图片。 |

照片处理支持裁切、旋转、增强、灰度与扫描效果。保存后仍可编辑内容、调整分类和知识点、添加图片。

## AI 解题与继续追问

- 支持题目文字、多张图片，以及文字与图片混合输入。
- 提供视觉模型、OCR + 文本模型、视觉辅助 + 文本模型三种解题方式。
- 可保存多套 AI 配置，选择使用模型和思考模式；思考模式可选默认、开启、关闭，实际支持取决于所配置的服务。
- 分别展示题目、答案和解析，支持数学公式排版与正文选择复制。
- 可停止请求、重新解题、添加图片继续追问，并查看解题历史。
- 将解题结果保存为错题，保留题目、答案、解析和图片，便于后续整理与复习。

AI 功能使用自行配置的服务地址、模型和 API Key；题目文字或所选图片会按解题方式发送到该服务。本地 OCR 使用前需下载相应组件。

## 按科目和知识点整理

错题库支持搜索、筛选、排序和批量选择。题卡展示完整题目，以及科目、题型、难度和复习状态；详情页集中查看图片、答案、解析与复习记录。

按知识点查看关联错题和学习情况，进入专项复习。知识点与科目关联，编辑错题时也可以调整知识点。

## 每日复习与学习反馈

- 设置每日题量、科目安排和抽取方式：按遗忘曲线抽取到期错题，或从计划中的错题随机抽取。
- 查看今日计划和接下来的题，选择具体题目开始复习。
- 在原题图片与“识别题目 + 裁剪图”之间选择一种展示方式。
- 查看答案后记录忘记、生疏、掌握或熟练，保存每次复习反馈。
- 通过进度、日历和打卡查看学习记录，并按知识点进行集中练习。

## 导出题目 PDF，回到纸上练习

从错题库选择题目，或打印今日复习计划。导出前可预览、保存 PDF，也可调用系统打印。

- **识别题目排版**：保留题目文字、公式、必要配图和作答区，默认不导出原图。
- **黑白照片排版**：对题目照片进行黑白处理，用图片呈现原题，保留题目小标题和作答区。
- 汇总题目数量、各科题量和导出时间，支持多题分页。

## 本机数据与备份

错题、图片、复习记录和设置保存在本机。支持导出 `.tiji` 备份、检查备份内容，以及合并恢复或替换恢复数据；API Key 在本机加密保存，不写入备份。

## 选择适合自己的外观

支持跟随系统、浅色和深色模式，以及晴蓝、松绿、湖青、鸢紫、玫粉、琥珀、靛青、可可八种主题色。一级页面通过底部导航切换，二级页面返回时保留进入前的浏览位置。

## 开始使用

1. 在 Android 8.0 及以上设备安装题迹。
2. 从错题库录入题目；使用 AI 功能时，先在设置中填写 AI 配置。
3. 整理科目和知识点，开启复习计划，设置每日题量。
4. 按计划复习，或导出题目 PDF 进行纸上练习。
